# aivloader

این افزونه امکان بارگذاری فایل‌های AIV سفارشی برای هوش‌های مصنوعی مشخص را فراهم می‌کند.

برای این کار از افزونهٔ `files` استفاده می‌کند.

**انتخاب منصفانهٔ قلعهٔ هوش مصنوعی** (به‌طور پیش‌فرض خاموش): از میان نقشه‌های قلعهٔ به یک اندازه مناسب، هر هوش مصنوعی یکی را تصادفی برمی‌گزیند، نه بیشتر اولی را.
